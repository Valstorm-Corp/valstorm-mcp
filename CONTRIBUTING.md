# Contributing to Valstorm MCP Server

Thank you for your interest in the Valstorm Hosted MCP Server!

## 1. Dedicated Development Team & Copyright Policy

The Valstorm MCP Server (`apps/valstorm-mcp-server`), CLI, Agent Runtime, and core platform modules are developed, maintained, and architected exclusively by the core engineering team at **Valstorm LLC**.

### No External Code Contributions Accepted
To protect intellectual property, prevent code contamination, ensure enterprise architectural integrity, and maintain **100% unified copyright ownership under Valstorm LLC without third-party fragmentation**, **we do not accept external pull requests, code patches, or direct repository contributions from third parties**.

Any Pull Requests (PRs) submitted by external individuals or organizations will be automatically and respectfully closed without merging.

---

## 2. How the Community Can Participate

While we do not accept external code patches, community feedback, discussions, and ecosystem involvement are welcome:

1. **Bug Reports**: If you encounter an unexpected error, reproducible bug, or unexpected behavior in MCP tools or SSE/Streamable HTTP transports, please open an Issue with:
   - A clear description of the issue.
   - Exact steps to reproduce.
   - Client details (Claude Desktop, Cursor, Goose, custom FastMCP client).
   - Sanitized terminal logs, error traces, and request payloads.
2. **Feature Requests & Ideas**: We value feedback on how Valstorm MCP tools solve autonomous agent workflows and enterprise integrations. Please share your suggestions and tool use cases in GitHub Discussions or Issues.
3. **Security Vulnerabilities**: If you discover a potential security vulnerability, please do **not** disclose it in a public issue. Report it immediately and privately to `security@valstorm.com`.
4. **Third-Party Agent Integrations**: We strongly encourage developers and organizations to build custom agents, clients, and IDE integrations consuming the standard MCP protocol endpoints provided by this server.
